# 💳 8월 신용카드 가계 정산 & 지출 분석 대시보드

신용카드(KB국민카드 + 신한카드) 이용대금명세서를 가계 관리기간(`06.24 ~ 08.23`)에 맞춰 자동 분류하고, 와이프 청구액·회사 출장비·개인 용돈을 실시간으로 정산 및 시각화하는 인터랙티브 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **4대 정산 분류 체계**:
   - 🔴 **와이프 최종 청구액 (공금/고정비)**: 아파트관리비, 도시가스, 대형마트, 배달식비, 쿠팡 생필품, 온라인 쇼핑 등
   - 💼 **회사 청구 (출장비)**: KTX 고속철도 (회사 실비 환급 대상)
   - 🟢 **남편 본인 부담 (내 용돈)**: 편의점, 개인 커피(모모스커피 등), 개인 취미
   - 🟡 **미분류 확인 필요**: 온라인 쇼핑몰 간편 지정 기능 제공
2. **📈 주식형 HTS 스타일 지출 분석 차트**:
   - 일별 지출 추이 (Area 라인 + 거래량 바)
   - 청구 vs 용돈 vs 출장비 비교 곡선 & 누적 지출 곡선
   - **호버링 그룹별 툴팁**: 날짜 포인트에 마우스 호버 시 [청구/출장비/용돈] 그룹별 사용처 및 금액 분리 표시
3. **📅 관리기간 경계선 시각화 월간 캘린더**:
   - `7월 관리기간 (06.24 ~ 07.23)` & `8월 관리기간 (07.24 ~ 08.23)` 컬러 띠 시각화
   - 카드사별 실제 출금일(KB 8/7, 신한 8/21) 뱃지 표기
   - 관리기간별/유형별 원클릭 필터링
4. **실시간 100% 양방향 동기화 & 영구 보존**:
   - 상단 간편 지정과 하단 테이블 대분류 드롭다운 완벽 일치
   - 브라우저 `localStorage` 연동으로 새로고침 및 재접속 시에도 수정 데이터 100% 보존
5. **💬 카카오톡 청구서 원클릭 복사**:
   - 출장비/용돈 제외 및 항목별 요약 문구 클립보드 복사
